{% load static %} {% block title %}{% endblock %} {% comment %} Canonical URL. Every page gets one, defaulting to its own path with the query string dropped. The query string is dropped on purpose. `?page=2`, `?utm_source=…` and the bare URL are three different addresses to a crawler, so without this the ranking a page earned is split three ways, and the version that surfaces is whichever one happened to be linked. A page that genuinely is a distinct address — a paginated list, a filtered view — overrides the block. {% endcomment %} {% comment %} Indexing rules per page. The default is to allow, and every staff-only template overrides this block with `noindex, nofollow`. This is not the same control as robots.txt, and having one is not a substitute for the other. `Disallow` stops the crawl; a URL blocked that way can still be listed in results — titled from an inbound link, with no description — because the crawler was never allowed to fetch the page and read this tag. `noindex` is what actually keeps a page out. The two are used together here. {% endcomment %} {% comment %} Open Graph / Twitter defaults, so a page that sets nothing still shares with a title and an image rather than a bare link.
